# DeeNAI
DeeNAI (pronounced "dee-en-ay.") aims to be the structure you need when vibe-coding your next project. 
Gives you a starting point without all the bulk of a full framework.

This repo is mostly vibe-coded itself, so take that into account when using anything provided here.

At the moment created with a Rust project in mind. 
Could be expanded on in the future where all core structure stays here while anything language specific gets its own repo.
